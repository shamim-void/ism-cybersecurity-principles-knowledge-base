# 📖 Cybersecurity Glossary

| Term | Definition |
| :--- | :--- |
| **CIA** | Confidentiality, Integrity, Availability – the three core security objectives |
| **SIEM** | Security Information and Event Management – a system that aggregates and analyses logs |
| **FDE** | Full Disk Encryption – encrypts the entire storage device |
| **MFA** | Multi‑Factor Authentication – requires two or more verification methods |
| **JIT** | Just‑In‑Time access – temporary, time‑bound elevated privileges |
| **BCP** | Business Continuity Plan – how to keep operating during a disruption |
| **DR Plan** | Disaster Recovery Plan – how to restore IT systems after a disaster |
| **IR Plan** | Incident Response Plan – steps to handle a security breach |

# 🧭 Navigation Pathways

## 👔 CISO / Board Member
*Focus: Risk, accountability, and budget.*
1. Read the [Cheat Sheet](01-framework-overview/cheat-sheet.md) for a 1‑page overview.
2. Review the [Maturity Model](README.md#-maturity-model-levels-1-5) to set your target.
3. Use the [Risk Assessment Template](05-templates/risk-assessment-template.md).

## 💻 Security Engineer / Admin
*Focus: Hardening, configuration, and logging.*
1. Follow the [Implementation Checklist](04-implementation-guide/implementation-checklist.md).
2. Focus on PRO‑04 (Attack Surface) and PRO‑08 (Encryption).
3. Set up DET‑01 (Centralised Logging).

## 🔍 Auditor / GRC Analyst
*Focus: Evidence, gaps, and compliance.*
1. Check the [ISO 27001 Mapping](02-cross-walk-register/ism-iso27001-mapping.md).
2. Use the [Gap Analysis Template](06-assessment/gap-analysis-template.md).

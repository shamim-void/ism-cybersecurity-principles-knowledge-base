# 📋 ISM Cybersecurity Principles – Cheat Sheet

| Code | Principle | Quick Action |
| :--- | :--- | :--- |
| **GOV-01** | Executive accountability | Add cyber to board charter |
| **GOV-02** | CISO leadership | Appoint a CISO |
| **GOV-03** | Risk management | Embed in ISO 31000 framework |
| **GOV-04** | Resourcing | Allocate budget and headcount |
| **GOV-05** | Risk acceptance | Document residual risk approvals |
| **GOV-06** | Risk communication | Share risks with stakeholders |
| **GOV-07** | Continuous improvement | Review risk process annually |
| **IDE-01** | Asset identification | Inventory all systems |
| **IDE-02** | Business criticality | Rank systems by importance |
| **IDE-03** | CIA requirements | Define confidentiality/integrity/availability |
| **IDE-04** | Risk identification | Document risks for each system |
| **PRO-01** | Secure lifecycle | Plan → Design → Build → Test → Deploy → Maintain → Decommission |
| **PRO-02** | Secure by design | Apply secure defaults |
| **PRO-03** | Trustworthy suppliers | Vet all vendors |
| **PRO-04** | Attack surface reduction | Close unused ports and protocols |
| **PRO-05** | Secure administration | Use separate admin accounts |
| **PRO-06** | Vulnerability management | Patch within agreed SLAs |
| **PRO-07** | Trustworthy software | Only allow approved executables |
| **PRO-08** | Data encryption | Enable FDE + TLS 1.3 |
| **PRO-09** | Content filtering | Inspect cross‑domain traffic |
| **PRO-10** | Proven backups | Test restores quarterly |
| **PRO-11** | Trustworthy personnel | Screen all staff |
| **PRO-12** | Least privilege | Grant minimum necessary access |
| **PRO-13** | Robust access control | Enforce MFA and conditional access |
| **PRO-14** | Awareness training | Deliver annual cyber training |
| **PRO-15** | Physical access | Restrict and monitor datacentres |
| **DET-01** | Centralised logging | SIEM or log aggregator |
| **DET-02** | Event detection | Analyse logs in real‑time |
| **DET-03** | Incident identification | Triage events within SLAs |
| **RES-01** | Incident planning | Have IR, BCP, DR plans |
| **RES-02** | Incident reporting | Notify internal and external stakeholders |
| **RES-03** | Incident response | Contain, eradicate, recover |
| **RES-04** | Lessons learnt | Capture improvements post‑incident |
| **REC-01** | Business resumption | Accept residual risk before restarting operations |

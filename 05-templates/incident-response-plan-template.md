## 3. Incident Severity Levels
| Level | Description | Escalation |
| :---: | :--- | :--- |
| 1 | Low (minor) | Internal team |
| 2 | Medium | CISO notification |
| 3 | High (critical) | Board + external reporting |

## 4. Response Phases
1. **Triage** – Confirm incident
2. **Containment** – Isolate affected systems
3. **Eradication** – Remove root cause
4. **Recovery** – Restore from backups
5. **Post‑incident** – Lessons learnt

## 5. Communication Matrix
| Stakeholder | When to contact | Method |
| :--- | :--- | :--- |
| Internal team | Immediately | Phone / Signal |
| Executive | Within 1 hour | Email / Briefing |
| Regulator | Within 24 hours (if required) | Formal report |

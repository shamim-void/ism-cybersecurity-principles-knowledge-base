# Case Study 3: Defence – Automated Access Removal

**Sector:** Defence

**Scenario:** Manual access removal was slow, creating security gaps when personnel exited.

**Key ISM Principles Applied:**
- PRO-11 (Trustworthy personnel)
- PRO-12 (Least privilege)
- PRO-13 (Robust access control)
- DET-02 (Event detection)

**Outcome:** Automated, immediate access revocation. Reduced insider threat risk. Demonstrable compliance with Defence Security Principles Framework.

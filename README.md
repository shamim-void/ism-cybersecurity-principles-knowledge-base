## 📊 Maturity Model (Levels 1–5)

| Level | Name | Description |
| :---: | :--- | :--- |
| ⬜ **1** | Initiated | Not implemented or partial |
| 🟨 **2** | Initial | Ad‑hoc, inconsistent |
| 🟧 **3** | Developing | Per‑project, standardised |
| 🟩 **4** | Managing | **Org‑wide standard practice** (target) |
| 🟦 **5** | Optimising | Continuous improvement, automation |

> [!IMPORTANT]
> For **Australian Government** and **Critical Infrastructure**, Level 3 is the **minimum** expected. High‑value assets must reach **Level 4**.

## 📊 Maturity Model (Levels 1–5)

| Level | Name | Description |
| :---: | :--- | :--- |
| 1 | Initiated | Not implemented or only partially |
| 2 | Initial | Implemented ad‑hoc |
| 3 | Developing | Implemented per project |
| 4 | Managing | **Standard practice** across organisation |
| 5 | Optimising | Continuous improvement focus |

> [!IMPORTANT]
> For government and critical infrastructure, **Level 3** is the minimum expected. High-value assets require **Level 4**.
